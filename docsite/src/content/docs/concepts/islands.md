The **Island** is a visual representation of the state of a Skylands _daemon_ process. When you run the `devworld`, you
get a daemon process for free. Otherwise, you run `skylands daemon ...` to start and stop daemons. The daemon process
is what controls your agents and their corresponding sessions, approvals, rejections, permissions, and more. Any work
an agent does ultimately has to go through the daemon process.

When using the 3D world visualization, clicking on an island will navigate to it and bring up a property sheet on
the side. This property sheet is the primary way that you will interact with daemon processes (though CLI commands
are always available for the so inclined).
