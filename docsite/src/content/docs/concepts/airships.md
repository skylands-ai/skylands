title: Airships
description: Airships
---

Airships are the avatars of individual agents projected into the 3D world visualization. As an agent moves
from file to file doing work, so too will the airship lift off and land on a new file representation
in a terrace. 

Multiple agents collaborating within a single terrace will show up as different airships. Each agent
type (e.g. Claude, Codex, Gemini, etc) has its own distinct shape and color. Clicking on the airship
will bring up the properties of that particular agent instance in that particular repository.
