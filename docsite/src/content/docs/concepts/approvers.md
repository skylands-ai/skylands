---
title: Approvers
description: Approvers
---

An **approver** is a _device_ from which a session authorization can originate. When a running agent encounters a task that requires elevated permissions from a human, Skylands will handle that authorization request. Approval requests are accessible
centrally from the Citadel or individually when looking at its agent session.

Approvers are added by giving them a short-lived device registration URL, similar to how streaming media apps like Netflix give you a quick way to add an authorized viewing device like a smart TV.

In the current version of Skylands, devices not registered as approvers can't see or interact with _any_ data part of a world.
