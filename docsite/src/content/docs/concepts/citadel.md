---
title: Citadel
description: The Citadel
---

The **Citadel** is a virtual construct that represents a single point of aggregation within a world. It doesn't matter whether
there is one citadel server running or a dozen: the data and functionality scopes remain the same. 

You use the citadel as a point of reference for all things global. This includes a global inbox used to manage your agent sessions, a set of pending approvals, manage the enrollment of daemons, and manage the list of valid _approvers_, which
are authorized browsers, and _not_ individual people.
